# Project Overview

This repository provides an overview of my social media project, linking to the separate repositories for the frontend and backend code.

Developed a full-stack social media web application that addresses user connectivity and engagement by enabling user authentication (sign-up, login, email verification, and password reset via Nodemailer) and facilitating post creation with images, GIFs, and videos. Users can like, comment, and manage friend requests, enhancing social interaction. Profile management features allow users to personalize their experience.

Technologies Used: ReactJS, Tailwind CSS, NodeJS, ExpressJS, MongoDB

## Repositories

- **Frontend**: [Frontend Repository Link](https://github.com/faris808/mern-new-social-media-frontend)
- **Backend**: [Backend Repository Link](https://github.com/faris808/mern-new-social-media-backend)

Both repositories together form the complete project, with the frontend using React and the backend built on Node.js.
